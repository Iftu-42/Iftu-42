### `01 /` A little about me

I'm a **Software Engineering student** passionate about how thorough system analysis, clean engineering, and visual design come together. Before jumping into code, I focus heavily on **research, requirement identification, and writing clear Software Requirements Specification (SRS) documents**—ensuring every feature solves the right problem from the start.

Beyond development, I'm interested in education, visual communication, automation, and creating opportunities for people to learn practical skills.

- 🎓 **Education:** Software Engineering student
- 📋 **System Analysis & SRS:** Strong at pre-code research, requirement gathering, use-case modeling, and structured **SRS documentation**
- 💻 **Development:** Focused on web development and software engineering fundamentals
- 🧠 **Problem Solving:** Practicing algorithms and data structures through LeetCode
- 📊 **Data:** Exploring data science, Python, and SQL
- 🎨 **Design:** Exploring graphic design, typography, and interface design
- 🎬 **Video & Motion:** Short-form animation, video editing, and visual storytelling
- 📚 **Leadership:** Founder and Trainer at **IELTS Ethiopia**
